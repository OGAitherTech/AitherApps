# Aither Apps

Aither Apps is an iPhone-inspired home screen for the Aither app collection.

## v1.0
- iPhone-style black home-screen layout
- Responsive 6-column desktop / 4-column mobile grid
- Aither blue neon shield-style app tiles
- Working links to Aither AI, Aither Web, Aither Calculator, Aither Maps, Aither Clock, Aither Weather, and Aither Notes
- All / Aither / Tools filters
- Live clock
- Mobile safe-area support
- GitHub Pages ready

## GitHub Pages
Enable **Settings → Pages → Deploy from a branch → main → / (root)**.
